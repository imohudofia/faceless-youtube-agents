# 02 — Content Format & Script Rules (the virality structure)

_Distilled from a proven reference channel (~100k subs, ~4.9M views on 21 videos) + hook/retention best practices. This IS the channel's script formula. The pipeline follows this for EVERY video._

## TITLE FORMULA
- "[Number] [Genius/Surprising] Uses of [cheap item] Most People Don't Know"
- "[Number] Places Seniors DON'T Know Give BIG Discounts"
- "[Number] MORE [X]" (sequel framing for proven winners)
- Number + curiosity gap + "most don't know / DON'T know". Keep main keyword in first ~5 words.

## VIDEO STRUCTURE (reverse countdown)
1. **HOOK (first 30–60s)**
   - Name the cheap/overlooked item or premise.
   - Big value promise + dollar contrast ("this $1 bottle replaces $500 of products").
   - Gentle us-vs-them ("they'd rather sell you an $8 spray with the same ingredient").
   - Tease #1 ("stick around for number one — the biggest one of all").
2. **REVERSE COUNTDOWN (N → 1)** — each item = 3 beats:
   - Name it (Number 6: ...)
   - How to (specific, doable)
   - Why it matters (saves money / makes things last / old-school trick most forgot)
3. **RETENTION RE-HOOKS** every ~5–7 items ("we're halfway, but the next ones save the most...") + one light curiosity aside.
4. **MID-ROLL CTA** (~70–80% in): "Before number one — if you like straightforward tips that save money, hit subscribe and turn on notifications."
5. **NUMBER ONE PAYOFF** — the biggest/most surprising, teased all video.
6. **OUTRO**: "Which will you try first? Did I miss one? Comment — I read every one." + "YouTube thinks you'll like this next."

## VOICE / TONE (for script writing)
- Warm, calm, plain-spoken, unhurried, grandmotherly-but-vital.
- Lived experience, never claimed expertise.
- Short sentences. Concrete numbers ("3 cents," "$15 tub," "a cup").
- No medical claims. No fake studies. No false brand attacks.

## ANTI-AI-SLOP RULES
- Original phrasing (don't copy reference scripts verbatim).
- Vary hooks/wording across videos; don't reuse an identical template every time.
- Natural voice (hazel_2), real visual progression (many distinct shots), varied motion.
