# 10 — YouTube Description Writing (apply to every video)

_Binding rules for writing the YouTube description. You (the agent) write the description yourself, using the actual script and the real chapter timestamps from the assembled video. Tailored to ThriftyHazel (faceless frugality/household channel, manual upload, no lead magnet or affiliate yet)._

---

## STRUCTURE (in this order)
1. **First 1–2 sentences (the most important part):** a punchy hook that restates the video's promise and front-loads the main keyword. This shows in search/below-the-fold, so make it specific and benefit-driven. No "In this video..." filler. No links here.
2. **Short context paragraph (2–4 sentences):** expand the value — what they'll learn / save, in Hazel's warm, plain voice.
3. **Chapters (CONDITIONAL — see rule below).**
4. **Comment CTA:** invite engagement, e.g. "Which of these will you try first? Tell me in the comments — I read every one." + a subscribe nudge.
5. **Disclaimer (always):** "These are general money-saving and household tips that work for me — please use your own good judgement."
6. **Hashtags:** exactly 3, on the last line (one broad, one specific, one branded), e.g. `#moneysavingtips #vinegarhacks #ThriftyHazel`.

## CHAPTERS — conditional rule
- If the video is **8 minutes or longer**, add chapter timestamps (YouTube auto-creates chapters when the description has timestamps starting at 00:00, each ≥10s apart).
  - Use the REAL timestamps from the assembled video (you know each segment's start time from the slide durations).
  - First line must be `00:00 — [hook label]`.
  - 6–12 chapters; each title a short curiosity-gap label, NOT "Intro/Outro" (e.g. "00:00 — The $1 bottle that replaces $500", "01:12 — #5: Soft towels again").
- If the video is **under 8 minutes** (like the vinegar test), chapters are OPTIONAL — skip them; they add little on short videos.

## VOICE / RULES
- Warm, plain, relatable Hazel tone. Short sentences.
- Front-load keywords naturally in the first 125 characters (no keyword stuffing).
- NO lead magnet, NO affiliate links (the channel has none yet — do not invent them).
- No medical claims, no false brand attacks (consistent with skill 06).
- Total length ~600–1,500 characters is plenty for this niche.
- Plain text only; use line breaks for readability.

## TEMPLATE (fill with real content per video)
```
[Hook sentence with main keyword + benefit.] [One more sentence of promise.]

[2–4 sentence warm context paragraph: what they'll learn / save.]

[CHAPTERS here ONLY if video ≥ 8 min:
00:00 — ...
01:xx — ...
...]

Which of these will you try first? Let me know in the comments — I read every one. If you like simple ways to save money, hit Subscribe and turn on notifications.

These are general money-saving and household tips that work for me — please use your own good judgement.

#broadtag #specifictag #ThriftyHazel
```

## NOTE (if the engine already has a description feature)
The faceless-youtube-agents pipeline can draft descriptions. Use it, but make its output conform to THESE rules (structure, conditional chapters, disclaimer, exactly 3 hashtags, no lead magnet/affiliate). If its default template includes lead-magnet/affiliate slots, leave them out for now.
