# 03 — Character & Assets (consistency without reference-image support)

## THE KEY FACT
Gathos image API does NOT accept reference images, so it CANNOT reproduce Hazel. Therefore:
- **Hazel shots are NEVER generated by the pipeline.** They are REUSED from a pre-built library.
- **B-roll (items/scenes) IS generated by Gathos** (each item is standalone — no consistency needed).

## HAZEL IMAGE LIBRARY
- Location: `C:\Users\imoh2\Developer\faceless-youtube\hazel\host_library\`
- ~48 images, **`.jpeg` format** (NOT .png — important for the code to read correctly).
- Many shots have numbered variants, e.g. `hazel_approval_1.jpeg`, `hazel_approval_2.jpeg`.
- Filename families include: hazel_neutral, hazel_smile, hazel_concerned, hazel_surprised, hazel_approval, hazel_thinking, hazel_laugh, hazel_point_right, hazel_point_left, hazel_present, hazel_holding, hazel_one_finger, hazel_confident, hazel_3quarter, hazel_profile, hazel_lowangle, hazel_table, hazel_kitchen, hazel_livingroom, hazel_window, hazel_thumb_excited, hazel_thumb_surprised, hazel_thumb_warm (each may have _1/_2 variants).

## VARIANT-SWITCHING RULE (anti-repetition)
- When a shot type is needed and multiple variants exist, **randomly pick among the available variants.**
- Track which variants were used within a video so usage is spread (don't show the same exact file twice in one video if alternatives exist).

## HAZEL APPEARANCE (canonical, for reference only — do NOT regenerate via Gathos)
Woman ~50–54, youthful-mature; wavy shoulder-length salt-and-pepper hair (mostly dark with subtle grey, NOT white); round brown glasses; dusty teal cardigan over a beige collared shirt; clean 2D flat-illustration style.

## HOW HAZEL SHOTS ARE USED IN A VIDEO
- **Sprinkled Strategically:** Hazel should appear roughly **10 times in a 5-minute video**, and **20 times in a 15-minute video**.
- This ensures she stays ingrained in the viewer's mind as the host driving the channel.
- Intro hook: a Hazel shot (e.g., hazel_smile or hazel_present).
- Between items / transitions: use Hazel shots to keep brand presence.
- Majority of screen time = B-roll. When explaining specific steps or items, use rich, detailed B-roll images rather than Hazel.

## IF HAZEL EVER NEEDS A NEW POSE
- Generate it in Google Flow (Nano Banana Pro) using the existing reference image + a "keep this exact same character" lock phrase. Save into host_library\ as `.jpeg`. NEVER via Gathos.
