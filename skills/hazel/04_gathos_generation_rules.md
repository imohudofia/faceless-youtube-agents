# 04 — Gathos Generation Rules (images + voice)

## HARD RULES
- **Call Gathos via Python** (the engine's `lib/gathos_client.py` method). NEVER raw `curl` in PowerShell (causes quote/Bad-Request errors).
- Image format for this project = **`.jpeg`**.
- Project base: `C:\Users\imoh2\Developer\faceless-youtube\`

## VOICE (locked)
- Use Gathos cloned voice **`hazel_2`** for ALL voiceover. No substitutes.
- Voiceover is generated FIRST and becomes the master timeline; visuals/captions are built to it (prevents audio-video desync). Never run a post-assembly voice-changer.

## B-ROLL IMAGE RULES
- Only B-roll/items/scenes are generated by Gathos (NOT Hazel — see 03).
- **MANDATORY STYLE ANCHOR — append to EVERY B-roll image prompt:**
  > `, clean 2D flat-illustration style, simple flat shading, soft friendly muted colors, minimal uncluttered background, gentle thin vector outlines, no text, no words, no labels, 16:9`
- This keeps all B-roll matched to Hazel's art style.
- **No text inside images** (titles/numbers/captions added later in code). The anchor enforces "no text".

### B-roll prompt template
`[item/scene/action]` + `[STYLE ANCHOR]`
Examples:
- "A plain white spray bottle on a clean kitchen counter, [STYLE ANCHOR]"
- "A sponge soaking in a glass bowl of gently fizzing water, [STYLE ANCHOR]"
- "A white porcelain sink, sparkling clean, [STYLE ANCHOR]"

## PER-VIDEO FOLDER STRUCTURE (engine creates per video)
```
faceless-youtube\hazel\<video-name>\
   script.txt
   voiceover.wav        (hazel_2)
   broll\               (Gathos 2D B-roll, .jpeg)
   hazel_shots\         (picked from host_library, .jpeg)
   captions.srt
   final\               (assembled mp4 + thumbnail)
```

- [ ] Every B-roll prompt ends with the STYLE ANCHOR
- [ ] No text requested inside any image
